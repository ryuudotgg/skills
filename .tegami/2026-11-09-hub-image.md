### 🧰 Hub container image

`apps/hub/Dockerfile` builds the hub into a non root image on a digest pinned `oven/bun` 1.4.4 slim base, with Litestream backing up `/data/hub.db` when `LITESTREAM_REPLICA_URL` is set and restoring it into a new incarnation when the data directory is empty. `apps/hub/compose.yaml` runs it with a published port, and `compose.tailscale.yaml` puts it behind a Tailscale sidecar instead.
