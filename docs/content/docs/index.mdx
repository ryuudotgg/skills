---
title: "Introduction"
description: "Plan-driven skills for coding agents."
---

Work starts from a plan written to disk, nothing gets committed or pushed for you until you turn that on, and the output carries no slop. The skills are plain markdown and shell, so they work in any agent that reads a skills directory. I test them against Claude Code and Codex. See [Agents](/agents) for what runs where.

The foundation comes from [pstack](https://github.com/cursor/plugins/tree/main/pstack) by [Lauren Tan](https://x.com/poteto): the principle skills, the panel skills, routing work through playbooks, and the PR watcher. Portions also come from [Matt Pocock's skills](https://github.com/mattpocock/skills). The Greptile extension builds on Greptile's [greploop](https://github.com/greptileai/skills/blob/main/greploop/SKILL.md).

```sh
git clone https://github.com/ryuudotgg/skills && cd skills && ./install.sh
```
