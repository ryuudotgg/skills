## Install

Prerequisites: git, gh and Bun 1.4.0 or newer. Installing needs no Python.

```sh
git clone https://github.com/ryuudotgg/skills && cd skills && ./install.sh
```

`install.sh` symlinks this checkout's `skills/` into the canonical store at `~/.agents/skills`, then links those skills into the agent tool directories it finds. It creates `~/.claude/skills` when `~/.claude` exists, and `~/.codex/skills` when `~/.codex` exists. It also links into existing `~/.cursor/skills`, `~/.config/opencode/skills`, and `~/.copilot/skills` directories without creating them.

With no flags, stdin and stdout at a terminal, and `CI` unset, `skills install` asks for the delivery mode and optional reviewers. Canceling changes no skill links, agents or settings. Flags, redirected input or output, and any `CI` value skip the prompts. A missing interactive dependency is installed once with `bun install --frozen-lockfile`; non-interactive installs need no network.

When Claude Code is installed, it copies `agents/` into `~/.claude`. A personal skill link or agent file with the same name is left alone, and the output lists it on a `skip` line with the reason.

Whenever `~/.codex` (or `CODEX_HOME`) exists, it adds missing skills entries to that directory's `hooks.json`. All four hook entries run the skills CLI through the `AGENTS_DIR` link, which defaults to `~/.agents/skills`. An entry this repository shipped for a retired hook is switched to its replacement in place. Personal entries are left alone. You can rerun it safely. By default, nothing is staged, committed, pushed, or posted unless you turn it on.

The installer prints the [Claude hooks block](/agents/claude-code) for you to paste. It never writes Claude settings. It removes old shipped hook copies only after rewiring Codex, and only when every registration it can find can be read and parsed and none names a file under the Claude hooks directory. It reads your Claude settings, your Codex `hooks.json`, and the `.claude/settings.json` and `.claude/settings.local.json` of every project in `~/.claude.json`. Personal files and the directory stay. The installer never creates that directory.
