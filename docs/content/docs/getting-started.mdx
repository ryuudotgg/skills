## Install

```sh
git clone https://github.com/ryuudotgg/skills && cd skills && ./install.sh
```

`install.sh` symlinks this checkout's `skills/` into the canonical store at `~/.agents/skills`, then links those skills into the agent tool directories it finds. It creates `~/.claude/skills` when `~/.claude` exists, and `~/.codex/skills` when `~/.codex` exists. It also links into existing `~/.cursor/skills`, `~/.config/opencode/skills`, and `~/.copilot/skills` directories without creating them.

When Claude Code is installed, it copies `agents/` into `~/.claude`. A personal skill link or agent file with the same name is left alone, and the output lists it on a `skip` line with the reason.

When `~/.codex` exists too, it adds missing skills entries to `~/.codex/hooks.json`. All four hook entries run the skills CLI through the `AGENTS_DIR` link, which defaults to `~/.agents/skills`. An entry this repository shipped for a retired hook is switched to its replacement in place. Personal entries are left alone. You can rerun it safely. By default, nothing is staged, committed, pushed, or posted unless you turn it on.

## Other Install Cases

<Accordions>
  <Accordion title="Custom Locations">
    Set the installer environment variables listed in [Configuration](/reference/configuration).
  </Accordion>
  <Accordion title="Python 3 Is Missing">
    The installer prints `skip` for `~/.codex/hooks.json` and adds no entries. All four hook commands need Bun, not Python 3.
  </Accordion>
  <Accordion title="Claude Code Is Not Installed">
    The installer prints `Done. Skills only` and skips the agent copies. Codex gets no hook entries without a Claude Code install. It still links skills into every agent tool directory it finds.
  </Accordion>
</Accordions>
